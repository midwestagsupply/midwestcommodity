# Logo files

`corn-left.png` / `corn-right.png`
  For light backgrounds. Black engraving, gold kernels.

`corn-left-reversed.png` / `corn-right-reversed.png`
  For dark backgrounds. White engraving, gold kernels. Not used on the site as built,
  but needed the moment the mark goes on anything black.

The wordmark is set in type, not artwork: see `.wm1` / `.wmrule` / `.wm2` in
`shared/site.css`. The yellow bar between the two lines is `--yellow`, the same
value as the notice banner and the call button.

Before this goes on a sign, a truck or an invoice, have the whole lockup redrawn
as vector so the letterforms match the Badger Grain mark exactly.
